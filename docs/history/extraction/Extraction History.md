# Extraction History

Semantic Projection Core was extracted during Chunk 2.8 from the former `astro_analysis_sdk.projection` package. Chunk 2 established contracts, engine behavior, registry-aware orthodox Synastry, context-aware projection, cognitive and Woofmapped reference profiles, projected term registries, deterministic rendering, materialization policy, scope-aware coverage, and a guard against silently flattening temporal activation packages.

The first planned post-extraction feature is a moderately rich implementation of `projected_temporal_activation_graph.v1`. See `Projected Timing and Temporal Activation Design.md`.
