# Implementation history

Everything under this directory is a non-normative development record. These documents preserve the reasoning and acceptance notes from the state of the project when each pass was written; future-tense statements and status claims may have been superseded.

For current behavior, begin with the [documentation index](../README.md).

## Collections

- [`legacy-design/`](legacy-design/README.md) — early architecture and design documents later replaced by current reference pages.
- [`extraction/`](extraction/README.md) — stabilization, repository extraction, and first post-extraction planning.
- [`chunk-2/`](chunk-2/README.md) — the original static projection implementation sequence.
- [`temporal-stage-c/`](temporal-stage-c/README.md) — temporal execution, operationalization, Woofmapped contexts, and synastry passes.
