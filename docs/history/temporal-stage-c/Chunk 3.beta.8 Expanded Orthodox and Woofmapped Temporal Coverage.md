# Chunk 3.beta.8 — Expanded Orthodox and Woofmapped Temporal Coverage

## Purpose

C8 expands profile coverage after Stage C production routing stabilized.

## Orthodox expansion

The Orthodox reference profile now projects nearly the complete canonical object layer. Directly modeled primitives retain their specialized Orthodox mappings. Other canonical objects use an auditable identity projection that preserves the source name, source object type, canonical facts, provenance, and source references.

The only object intentionally omitted from the real natal fixture is the legacy `Fortune` lot alias when the canonical calculated `Part of Fortune` object is also present. This avoids duplicate semantic identity while preserving the canonical object.

Expanded coverage includes:

- True Node and Mean Node;
- Part of Fortune, Spirit, and Vertex;
- antiscia and contra-antiscia points;
- harmonic points;
- declination positions;
- dignity states;
- sect state;
- all existing planets, angles, houses, and major aspects.

The same expanded object coverage is reused by temporal projection. On the January 2026 reference fixture, all 12 activators and all 88 canonical activation arcs project successfully.

## Woofmapped timing

C8 does not add new Woofmapped primitives. It formalizes and regression-tests the existing temporal route:

- persistent Woofmapped activators;
- temporal relationship reuse;
- doghouse-domain state composition;
- standard production materialization;
- deterministic route receipts.

The Woofmapped temporal profile remains intentionally narrower than Orthodox because its ontology is experimental and domain-specific.

## Architectural rule

Orthodox identity projection is still projection, not source mutation. Canonical facts remain Foundry-owned; Core creates a deterministic Orthodox semantic representation and records whether the mapping was specialized or identity-preserving.
