# Roadmap

This page lists work not implemented in the current release. Completed development plans live under `history/`.

## Release integration and operations

- Replace AGF's permissive SPC dependency and internal profile-mapping imports
  before using AGF as a production orchestrator.
- Install and smoke-test the exact 0.10.0 wheel in the AstroWoof API's target
  Linux image; publication alone does not qualify a deployment environment.
- Turn the evidenced reproducible-build procedure into one maintained release
  command or workflow without weakening independent clean-archive verification.
- Evaluate signed annotated tags and GitHub's platform release-immutability
  control for future releases. SPC 0.10.0 has neither and relies on its
  non-moving tag plus mandatory wheel hash.

## Projection and extension

- Provide a polished direct workflow for loading consumer-owned profile directories, complementing installed Python entry-point discovery.
- Evaluate externalized temporal forensic audit artifacts analogous to the static audit artifact.
- Grow semantic comparison utilities without moving synthesis into the projection engine.
- Consider richer lexical realization metadata and multilingual registries while keeping final prose downstream.

## Temporal

- Add event, daily, monthly-index, or streaming views as materializations over the same activation arcs where consumer demand warrants them.
- Expand permanent rich-fixture coverage for Composite and Davison temporal targets.
- Add temporal activation of synastry graphs after AGF defines a canonical temporal-synastry source contract and fixtures.
- Revisit profile-specific state composition and intentional scope exclusions only through explicit profile-version evolution.

## Synastry and groups

- Add richer permanent human-dog and dog-dog synastry fixtures.
- Design a canonical group/pack source contract before implementing pack or household projection.
- Continue auditing relationship families and aliases against explicit profile scope.

## Woofmapped

- Add direct-house traceability alongside applied Doghouses if the source and consumer requirements justify it.
- Add downstream forecast-selection policies and narrative synthesis without embedding them in SPC.

## Explicit non-goals

SPC does not plan to absorb astrological calculation, calibrated empirical validation of experimental profiles, clinical or veterinary diagnosis, final claim synthesis, report publishing, or application-specific runtime rules.
